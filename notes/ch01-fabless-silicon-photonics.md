# Chapter 1 — Fabless silicon photonics

> 书中位置：Part I Introduction · 约 pp. 3–27  
> 本章几乎没有公式。过关标准：能向别人讲清「为什么做硅光、硅能做什么 / 不能做什么、后文每个大器件在解决哪条约束」。

## 1. 这一章在干什么

第一章是全书的**地图**，不是器件设计章。它回答三件事：

1. 硅光为什么突然成了一条可走的产业路线（fabless + CMOS 供应链）
2. 应用拉力从哪来（尤其数据通信）
3. 技术短板在哪：波导 / 调制 / 探测 / 光源 / 光电集成 —— 后文每一章都在填这些坑

读法：标三类句子——**动机**、**物理/材料约束**、**工艺与产业约束**。公司名、MPW 年表扫一眼即可，不必背。

## 2. 核心论点（用自己的话记住）

### 2.1 红利不是「硅光学性能全面最好」

近红外波段硅能透光，但真正关键的是：

- **超高折射率衬度**（SOI 上 Si / SiO₂）→ 强束缚、紧弯曲、小器件
- **能借用成熟 CMOS 制造与 fabless 生态** → 可量产、可分摊成本
- **通信 / 算力对带宽密度与功耗/bit 的刚需** → 有人买单

高对比度的另一面：散射损耗、工艺误差、偏振敏感都会被放大。后文波导、耦合器、环的「设计规则」都绕不开这件事。

### 2.2 Fabless 立场

设计者面对的是 **PDK、设计规则、MPW（多项目晶圆）**，不是自己建厂。  
从第一章起就建立习惯：每个器件问一句——「能落进某套工艺规则吗？」

### 2.3 光源是短板

体硅很难做高效片上激光。常见现实：

- 外置激光 + 片上耦合
- 异质 / 混合集成 III–V
- 其他探索路线（后文 Ch8 展开）

所以硅光链路往往是「硅做被动与部分有源 + 别处解决发光」。

### 2.4 光电集成两条大路

- **单片集成（monolithic）**：光与电尽量做在同一工艺流里
- **多芯片集成（multi-chip）**：分开优化再封装在一起

没有绝对赢家；指标、成本、良率、供应链一起决定。第一章只要建立这个二分框架。

## 3. 按小节导读

### 1.1–1.2 引言与「下一个 fabless 半导体产业」

抓住：光子学历史上偏「实验室特制」；硅光试图把设计—流片—测试拉成更接近 IC 的流程。Mead & Conway 式思路（少而够用的物理 + 可落地的设计实践）贯穿全书。

### 1.3 应用（以数据通信为主）

短距光互连、收发模块等场景，驱动指标通常是：

- 带宽密度
- 功耗 / bit
- 成本与可量产性

**不等于**「把波导损耗实验室做到极限就够」。做功率预算时要把封装、耦合、良率放进脑子。

### 1.4 技术挑战与现状（后文预告片）

| 主题 | 第一章要带走的问题 | 后文主要落点 |
|------|-------------------|--------------|
| 波导与无源 | 束缚 vs 损耗 vs 工艺敏感 | Ch3–5 |
| 调制器 | 怎么高效改相位 / 强度，速度与损耗怎么换 | Ch6 |
| 探测器 | 响应度、带宽、暗电流直觉 | Ch7 |
| 光源 | 为何难、集成路线有哪些 | Ch8 |
| 光电集成 | 单片 vs 多芯片 | 系统与封装相关章 |

### 1.5 机会

器件工程、系统工程、工具链（含光电协同设计）、DFM / 良率、以及 MPW / 工艺标准化。  
对学习者：你后面每做一个「最小系统」，都是在练 1.5 里说的「从器件到系统」过渡。
